# 凯知选 RˉkAI

这是一个 React + Vite 的个人店铺示例，包含简化的商家工作台和买家页面。

## 在电脑上运行

1. 解压源码 ZIP，进入包含 `package.json` 的文件夹。
2. 安装 Node.js 20.19+ 或 22.12+。
3. 在此文件夹的终端运行 `npm install`，然后运行 `npm run dev`。
4. 打开终端显示的本地网址。

生成部署文件：`npm run build`，输出位于 `dist/`。

## 上传到 GitHub

在 GitHub 仓库页面选择 `Add file` -> `Upload files`，把解压后的项目文件和文件夹上传。不要上传 `node_modules` 或 `dist`。也可以在电脑上用 Git 提交并推送。

## 重要限制

商品、设置及订单目前保存在**当前浏览器的 localStorage**，不是服务端数据库。卖家在自己浏览器上架的商品不会自动同步到买家的浏览器；买家的订单也不会自动同步到卖家。页面没有接入在线支付、支付结果核验或自动发货。因此这个版本只能演示，不可当作已经能对外独立收款和管理订单的正式店铺。正式经营需要后端数据库、商家身份验证、正规支付渠道及支付回调核验。

此外，店内示例商品仅用于演示。正式销售前请替换为真实有权销售的商品，并检查授权及平台规则。
